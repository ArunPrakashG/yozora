# F7 Claude sessions module

## Summary

The reference module: shows how many Claude desktop sessions are out of sync across accounts, lists each account with its session count and age, and syncs on a button press. It replaces the plain-text custom module.

## In scope

- Bar item: sync icon, alert badge with a count when out of sync.
- Popover: per-account rows and a Sync now button.
- Uses the existing claude-session-sync script as its data source.

## Out of scope

- Changing how sessions are copied.
