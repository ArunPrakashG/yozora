# F8 CachyOS updates module

## Summary

The second reference module: pending repo and AUR updates with versions, news warnings that need attention before updating, and an Update button that opens the user's terminal running the update.

## In scope

- Bar item: count badge and a warning tone if news needs attention.
- Popover: grouped list of updates and the news warnings.
- Sources: checkupdates and paru -Qua.

## Out of scope

- Running the update inside the popover.
