# F1 Module schema

## Summary

A new `yozora-module` crate defines the strict, versioned types every module speaks: the manifest, the bar item, the popover view tree and the action messages. Unknown fields are errors, and styling is limited to semantic tones and sizes.

## In scope

- Manifest type (`module.toml`): name, version, icon, refresh mode (interval or push), declared actions.
- Bar item type: icon, optional text, optional badge, tone.
- Popover view tree: Title, Section, Row, Toggle, Slider, Progress, Badge, Button, Empty, Confirm.
- Host-to-module and module-to-host JSON-lines messages.
- Semantic tones: neutral, accent, success, warning, danger.

## Out of scope

- Rendering (F4) and process handling (F3).
- Any colour, pixel size, font or radius field.
