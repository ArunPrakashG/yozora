# F3 Module runtime

## Summary

The bar discovers module manifests, runs and supervises each data process, parses its JSON lines against the schema, sends action messages back, and records a standard error state when a module misbehaves.

## In scope

- Discover manifests from the system and user module directories.
- Interval and push modes, restart with backoff on exit.
- Invalid output becomes an error state, never a broken layout.
- Actions go to the process (stdin) or run a manifest command; destructive ones are held for Confirm.

## Out of scope

- Drawing anything (F4).
- The CLI (F5).
