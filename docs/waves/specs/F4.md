# F4 Bar item and popover renderer

## Summary

The bar draws each module's item and opens its popover from the view tree, using the component kit. `module/<name>` becomes a placeable zone entry next to the built-ins, and `custom/<name>` stays as the plain-text legacy form.

## In scope

- `module/<name>` in bar zones.
- Bar item with icon, badge and tone; click opens the popover.
- Error state with a standard icon and message.

## Out of scope

- Removing `custom/<name>`.

## Acceptance criteria

```yaml criteria
AC1: {text: "A module placed in a zone renders its bar item and opens its popover", verify: "cmd:cargo test -p yozora-bar module_render"}
AC2: {text: "An errored module shows the standard error state", verify: "test:crates/yozora-bar/tests/module_error_state.rs"}
```

## Steps

- F4.1 Render module bar items and popovers from the view tree and register the zone entry.
