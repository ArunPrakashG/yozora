# F2 Component kit

## Summary

The fixed set of GPUI components that render a view tree: Row, Section, Toggle, Slider, Progress, Badge, Button, Empty and Confirm. Built-in popovers and modules both use them, so nothing can look different.

## In scope

- One GPUI component per view-tree node, themed from Yozora tokens only.
- Tone and size mapped to theme colours and spacing in one place.
- Light and dark theme support.
- Long text truncates its value, not its label.

## Out of scope

- Migrating the existing network, sound and devices popovers.
- Bar-item rendering (F4).
