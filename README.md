# Yozora

Yozora (夜空, "night sky") is an open-source desktop for Hyprland, written in Rust with
[GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui).

The first app is **Yozora Bar**, a top panel and Waybar alternative. It aims for spring-based
motion and near-zero cost when idle.

## Status

Pre-alpha. The design is approved and the Phase 1 spike (GPUI layer-shell panel and popover on
Hyprland) is next. Nothing is usable yet.
